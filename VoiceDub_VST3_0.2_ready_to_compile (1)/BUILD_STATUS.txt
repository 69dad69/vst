VST3 blocker in this environment:
CMake reaches JUCE FetchContent and then cannot resolve github.com. The failure happens before JUCE is available, so the VST3 wrapper compiler is not invoked here. This is an environment/network restriction, not a failing VoiceDub core build.

To continue without network access, place a JUCE source checkout on disk and run:
cmake -S . -B build -DVOICEDUB_JUCE_PATH=/path/to/JUCE -DCMAKE_BUILD_TYPE=Release
cmake --build build --target VoiceDub_VST3 -j

On Windows with Visual Studio 2022, build-windows.bat performs configure, core build/tests and VST3 build.
